# Rhinolophus sinicus gut microbiome

Computational methods and analysis scripts accompanying the manuscript:

**A global cross-species pathogen network reveals the evolutionary and transmission potential of the *Rhinolophus sinicus* gut microbiome**

## Supplementary methods

[Supplementary Methods (HTML)](Supplementary_Methods.html)

The document contains the analysis steps, command templates, scripts and associated parameters, including the network analysis for Figure 6.

To view the formatted document, open the HTML file link, select **Download raw file**, and open the downloaded file in a web browser. Alternatively, select **Code > Download ZIP**, extract the archive, and open `Supplementary_Methods.html`.

The scripts can be saved from the corresponding code blocks and run individually with the required software, input files and reference databases.
